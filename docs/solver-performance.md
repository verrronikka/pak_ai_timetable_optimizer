## Оптимизации backtracking (внедрено)

1. **MRV без `list.index`** — выбор задачи за один проход, splice вместо O(n) поиска индекса.
2. **Кэш загрузки слотов** (`_slot_load`) — сортировка кандидатов без `len(schedule[slot])` на каждом сравнении.
3. **Начальная сортировка** — degree (конкуренция teacher/group) + узость дней + тип аудитории.
4. **Порядок кандидатов `combined`** — загрузка слота → вместимость → нагрузка преподавателя.
