# Ограничения solver'а: руководство для backend/frontend

## Технические лимиты
| Параметр | Диапазон | По умолчанию | Влияние |
|----------|----------|--------------|---------|
| `max_search_steps` | 1K – 1M | 200K | Чем больше → выше шанс решения, но дольше выполнение |

## Бизнес-ограничения
1. **Учитель**: ≤ `max_weekly_hours` часов в неделю, только в `available_days`
2. **Аудитория**: тип должен совпадать с требованием предмета, вместимость ≥ размер группы
3. **Группа**: не более 1 занятия в один временной слот
4. **Предмет**: `hours_per_week` занятий должно быть размещено
