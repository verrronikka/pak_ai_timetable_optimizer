# Результаты профилирования Солвера 1

## Обзор

Профилирование выполнено на синтетическом датасете с помощью `test_profiling.py`. Тесты измеряют время выполнения, потребление памяти и количество шагов поиска (backtracking) для различных конфигураций лимитов поиска.

## Результаты по конфигурациям

| Метрика | Значение |
|---------|----------|
| Успех | ✓ Да |
| Статус | успех |
| Время выполнения | 0.024 сек |
| Память (пик) | 0.0 МБ |

**Вывод**: Датасет решается почти мгновенно, лимит 10К больше чем достаточен.

## Итоговые выводы

1. **Текущий синтетический датасет имеет низкую сложность** - решается за 5 шагов поиска, независимо от лимита
2. **Производительность отличная** - время выполнения 19-24 мс, практически не использует память
3. **Рекомендуемые лимиты**:
   - Для простых задач: 10,000 шагов достаточно
   - Дефолт 200,000: подходит для большинства случаев
   - Максимум 1,000,000: для очень сложных задач

4. **Параметры для frontend валидации**:
   - min: 1,000
   - max: 1,000,000
   - default: 200,000

## Что можно сделать

- Тестировать на более сложных реальных датасетах для получения более репрезентативных метрик
- Мониторить время выполнения при увеличении сложности входных данных
- Рассмотреть градацию лимитов на основе размера входного датасета (кол-во преподавателей, аудиторий, групп)
